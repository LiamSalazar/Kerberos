    Browser boundary

    • Raw tickets are never exposed to the browser.
    • Cryptographic material is omitted from the UI.
    • Opaque sessions must be verified with the Gateway.
    • Invalid identities and replay attempts are rejected by the runtime or automated tests.
    • The Gateway stays as the integration boundary for apps.
